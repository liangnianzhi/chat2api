先说清楚：为什么这里要你手动粘贴

厂商官网（比如 chat.deepseek.com）登录后的凭证存在你自己浏览器的存储里， 其他域名（包括本容器）按浏览器安全规则读不到。要自动读，就必须在容器里跑一个完整浏览器内核， 那是 500MB+ 的代价，与这个轻量镜像的初衷相背。

所以这里做的是：告诉你取哪个字段，你粘一次，容器加密存下来。

可以在同一浏览器里添加多个账号吗？可以。

关键点：容器里每个账号存的是它自己的 token，与你浏览器是否还在登录无关。

所以流程是：登录账号 A → 复制 token → 粘到下面保存 → 退出登录 → 登录账号 B → 复制 token → 再保存一次。

唯一需要注意的是：如果你用 同一个浏览器登录第二个账号，第一个账号在**厂商网站上**会被登出 —— 但那不影响已经保存在容器里的 token。除非那个 token 被厂商作废（比如主动“退出所有设备”），否则持续有效。
