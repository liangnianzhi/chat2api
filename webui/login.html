为什么这些字段要手动粘贴

厂商官网（如 chat.deepseek.com）登录后的凭证存在你自己浏览器的存储里， 其他域名（包括本容器）按浏览器同源策略读不到。要自动读就得在容器里跑完整浏览器内核， 那是 500MB+ 的代价。

所以这里做的是：告诉你取哪个字段，你粘一次，容器加密存下来。

多个同厂商账号怎么加（不会互相踢）

先说结论：容器里每个账号存的是自己的 token，互不影响。 加完一个账号后，即使你在浏览器里退出登录，容器里的那个账号依然可用。

真正需要注意的是 取 token 的那一刻：如果你在同一个浏览器窗口里登第二个号， 第一个号在厂商网站上会被登出（新号替换旧会话）。此时旧 token 通常仍在容器里有效， 但如果厂商发现异地/多会话，可能把旧 token 作废。

稳妥做法是用隔离的窗口登不同的号，这样两家会话互不干扰：

Chrome / Edge为每个账号开一个独立浏览器配置文件（右上角头像 → 添加），或用无痕窗口（快捷键 Ctrl+Shift+N）
Firefox多账户容器（Multi-Account Containers 扩展），或容器标签页
Safari新建隐私浏览窗口（Cmd+Shift+N）

无痕窗口关掉就清空，所以取完 token 直接关闭即可，不会与主窗口的账号互相踩到。
